# DCT-image-steganography

## Math Hell

This tool hides encrypted text inside images using Discrete Cosine Transform (DCT) algorithms. Unlike standard LSB methods, this tool is resistant to compression(to a degree).
Just so you know, the math almost made me forget who I was, but hey! Somehow it worked out okay in the end!
